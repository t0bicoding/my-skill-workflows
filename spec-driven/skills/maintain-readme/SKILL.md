# Maintain README

**Read:** `README.md`, and from the feature's spec only "Goal" and the function names (the `F-n` headings); or the one-shot change; or `setup-plan.md` of the project setup.

- Update only what users notice: what the project can do, how to start it, how to use it.
- Plain language, short sentences. Explain technical or domain terms or leave them out.
- Every command is copy-pasteable and has been run once.
- Details belong in the linked documents, not in the README.
- Remove or update "Status" when it is no longer true.
- English.
- Nothing visible changed → no edit.

Show the changes briefly; apply them after the user's OK.
